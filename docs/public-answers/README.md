# Public Answers

This folder stores human-readable answer packets for public math prompts that Truth Harness can solve, refute, or honestly bound with replayable evidence.

Each packet should follow [Public Answer Workflow](../PUBLIC_ANSWER_WORKFLOW.md) and cite:

- the source problem,
- the normalized claim,
- the trust label,
- receipts or benchmark suites,
- replay commands,
- limitations and review status.
